
🤖 Jarvis - AI Chatbot in Python

> Your personal AI assistant built with pure Python. No API. No Internet. Just logic.

---

✨ What is Jarvis?

Jarvis is a simple, smart chatbot that can have a real conversation with you.
I built it to understand how AI chatbots work - how they understand keywords, remember context, and reply naturally.

It's my Project 2 in my Building-In-Public journey as a BCA student specializing in Artificial Intelligence.

🚀 Features

- 👋 **Remembers Your Name** - Personalized replies throughout the chat
- 🕒 **Live Time & Date** - Ask "What is the time?" anytime
- 😂 **Random Jokes** - 3+ programmer jokes, never boring
- 🐍 **Python & AI Q&A** - Ask "What is Python?" or "What is AI?"
- 💬 **Natural Conversation** - Understands hello, thanks, help, bye
- ⚡ **Zero Setup** - No API key, no internet, no extra libraries

🛠️ Tech Used

- **Language:** Python 3
- **Libraries:** `random`, `datetime` (built-in only)
- **Concepts Used:** If-Else Logic, Functions, Loops, String Handling
